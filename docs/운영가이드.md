# 직원용 사용 가이드

## 매일 흐름 (홈 화면 '오늘 할 일' 순서대로)
2. **체크리스트** — 내 포지션(오픈/미들/마감) 탭에서 하면서 체크. 체크한 사람·시간이 자동 기록됩니다.
   - 미들 출근하면 **가게 입구 빗자루로 쓸기**부터.
   - 다 끝나면 "📋 보고용 복사"로 텔레그램에 올리기.
3. **재고·발주 체크** (14~16시) — 열면 어제 수량이 들어 있습니다. 바뀐 것만 고치고, 발주점 이하로 표시된 품목은 "+ 버튼"으로 발주 목록에 넣은 뒤 **텔레그램용 복사 → 텔레그램방**.
4. **일지** (마감 전) — 숫자 몇 개(에타·홀·조각·빙수·매출)와 메모만. 저장 버튼 없이 자동 저장 → "텔레그램 복사"로 보고. 더 자세한 항목은 "더 적기"를 펼치면 있습니다.
5. **퇴근** — 다 끝나고 홈에서 🔴 퇴근 한 번. 출근 시각은 찍지 않습니다.

## 메모 쓰는 법 (일지)
버튼 누르고 한 줄만 적습니다. 줄 앞 이모지로 색이 구분됩니다.
- `⏱` 시각 (누르면 현재 시각 자동)
- `😠` 컴플레인 · `⚠️` 이슈 · `🔧` 고장 · `📦` 입고 안 됨 · `🗑` 폐기
- `🎁` 서비스 · `📞` 예약·주문
- `✅` 사장님 확인 필요

## 근무표
- 달력에서 내 이름 색 칩을 보면 됩니다. 취소선은 휴무. 시간은 따로 적지 않고, 오픈·마감 같은 포지션만 표시합니다.
- 근무 변경 요청은 매니저에게. 매니저는 날짜를 눌러 바로 수정합니다.

## 퇴근 기록
퇴근 시각만 찍습니다. 늦게까지 남은 날을 봐두었다가 다른 날 일찍 보내주기 위한 것입니다. 사유가 있으면 "메모"에 한 줄 적어두세요.

## 매장 공용 컴퓨터로 쓸 때
1. 로그인 화면에서 "매장 공용 컴퓨터"에 체크합니다. (한 번만)
2. 그다음부터는 이름 버튼을 누르고 비밀번호만 치면 들어갑니다.
3. 다 쓰면 오른쪽 위 "사용자 바꾸기"를 누릅니다. 10분간 조작이 없으면 자동으로 잠깁니다.
4. 이름 버튼 목록은 관리자가 한 번 로그인한 뒤부터 나타납니다. 직원을 새로 추가했으면 관리자가 그 컴퓨터에서 한 번 로그인해 주세요.
