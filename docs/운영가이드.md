# 직원용 사용 가이드

## 매일 흐름 (홈 화면 '오늘 할 일' 순서대로)
1. **출근** — 홈에서 🟢 출근 (매장 도착 기준, 10분 전 출근)
2. **체크리스트** — 내 포지션(오픈/미들/마감) 탭에서 하면서 체크. 체크한 사람·시간이 자동 기록됩니다.
   - 미들 출근하면 **가게 입구 빗자루로 쓸기**부터.
   - 다 끝나면 "📋 보고용 복사"로 텔레그램에 올리기.
3. **재고·발주 체크** (14~16시) — 열면 어제 수량이 들어 있습니다. 바뀐 것만 고치고, 발주점 이하로 표시된 품목은 "+ 버튼"으로 발주 목록에 넣은 뒤 **텔레그램용 복사 → 텔레그램방**.
4. **일지** (마감 전) — 숫자 몇 개(에타·홀·조각·빙수·매출)와 메모만. 저장 버튼 없이 자동 저장 → "텔레그램 복사"로 보고. 더 자세한 항목은 "더 적기"를 펼치면 있습니다.
5. **퇴근** — 홈에서 🔴 퇴근.

## 메모 쓰는 법 (일지)
한 줄에 한 가지. 줄 앞 이모지로 색이 구분됩니다.
- `⏱` 시각 (버튼 누르면 현재 시각 자동)
- `🔴` 재고·폐기·발주 이슈
- `🔵` 서비스·특이사항
- `⭐` 고객·주문 이슈
- `✅` 사장님 확인 필요

## 근무표
- 달력에서 내 이름 색 칩을 보면 됩니다. 취소선은 휴무.
- 근무 변경 요청은 매니저에게. 매니저는 날짜를 눌러 바로 수정합니다.

## 출퇴근 시간이 잘못 찍혔을 때
출퇴근 메뉴 → 해당 날짜 "수정" → 메모에 정정 요청을 남기면 관리자가 시간을 고칩니다.
