# Firebase 설치 가이드 (사장님용)

로컬 데모 모드는 브라우저 하나에만 저장됩니다. 직원 각자 폰에서 같은 데이터를 보려면 아래 순서대로 한 번만 설정하면 됩니다. 비용은 카페 규모에서는 무료 범위입니다.

## 1. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 접속 (구글 계정 로그인)
2. **프로젝트 추가** → 이름 `cafesui-sonjoy` → 애널리틱스는 꺼도 됨 → 만들기

## 2. 로그인 기능 켜기
1. 왼쪽 메뉴 **빌드 → Authentication** → 시작하기
2. **로그인 방법** 탭 → **이메일/비밀번호** → 사용 설정 → 저장
3. **사용자** 탭 → **사용자 추가** → 이메일 `minji@sonjoy.cafe`, 비밀번호 6자 이상 → 추가
   - 이 계정이 사장님 계정입니다. 앱에서는 아이디 `minji`로 로그인합니다.
4. **설정** 탭 → **승인된 도메인** → 나중에 GitHub Pages 주소(`thsalswl900119-maker.github.io`)를 추가

## 3. 데이터베이스 만들기
1. **빌드 → Firestore Database** → 데이터베이스 만들기
2. 위치: `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
3. **규칙** 탭 → 내용을 전부 지우고 저장소의 `firestore.rules` 파일 내용을 붙여넣기 → 게시

## 4. 앱에 연결 정보 넣기
1. 프로젝트 설정(톱니바퀴) → **일반** → 아래 **내 앱** → 웹(</>) 아이콘 → 앱 이름 `sonjoy` → 등록
2. "SDK 설정 및 구성"에서 **구성** 선택 → `firebaseConfig = { ... }` 안의 값 복사
3. 저장소의 `js/config.example.js`를 복사해 `js/config.js`로 만들고 값 붙여넣기

```js
window.FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "cafesui-sonjoy.firebaseapp.com",
  projectId: "cafesui-sonjoy",
  storageBucket: "cafesui-sonjoy.appspot.com",
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};
```

> `js/config.js`는 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다. GitHub Pages로 배포하려면 `.gitignore`에서 그 줄을 지우고 올리세요. (apiKey는 공개돼도 Firestore 규칙이 보호합니다.)

## 5. 배포 (GitHub Pages)
1. GitHub 저장소 → **Settings → Pages** → Source: `Deploy from a branch` → `main` / `/ (root)` → Save
2. 몇 분 뒤 `https://thsalswl900119-maker.github.io/SONJOY/` 에서 열립니다.
3. 직원 폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 씁니다.

## 6. 첫 로그인과 직원 등록
1. 앱에서 `minji` / 비밀번호로 로그인 → 이름 입력 → 자동으로 **사장(owner)** 권한
2. **설정 → 직원 추가**: 이름, 아이디(영문), 권한(직원/매니저), 초기 비밀번호
3. 직원에게 아이디·초기 비밀번호를 알려주고, 로그인 후 **설정 → 비밀번호 변경**을 하게 하세요.

## 자주 묻는 것
- **비밀번호를 잊었어요**: Firebase 콘솔 → Authentication → 사용자 → 해당 계정 → 비밀번호 재설정
- **퇴사자**: 설정 → 직원 관리 → 비활성. 기록은 남고 로그인만 막힙니다.
- **데이터 백업**: 설정 → 전체 JSON 내보내기 (월 1회 권장)
- **콘솔에 "index required" 오류**: Firestore가 안내하는 링크를 눌러 색인을 만들면 됩니다 (1분).
