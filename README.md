# SONJOY — 카페스이 운영노트

우리가 해야 할 일들을 한곳에서. 직원 각자 로그인해서 **출퇴근 · 근무표 · 체크리스트 · 재고/발주 · 가게 스케줄 · 일지**를 기록하는 카페스이 전용 웹앱입니다.

권한: **사장(owner) > 매니저(manager) > 직원(staff)**. 사장만 권한 변경이 가능합니다.

## 바로 써보기 (로컬 데모 모드)

`index.html`을 브라우저로 열면 됩니다. Firebase 설정이 없으면 이 브라우저에만 저장되는 데모 모드로 동작합니다.

- 기본 계정: `minji`(사장) / `hyanga`(매니저) / `hyebin`, `haesun`(직원), 비밀번호는 모두 `000000`
- 데모 모드 데이터는 기기 간에 공유되지 않습니다. 실제 운영은 아래 Firebase 설정을 하세요.

## 실제 운영 설정 (Firebase, 무료) — 약 15분

여러 기기·직원이 같은 데이터를 보려면 Firebase(구글)가 필요합니다. 자세한 순서는 [docs/설치가이드.md](docs/설치가이드.md)를 보세요. 요약:

1. https://console.firebase.google.com 에서 프로젝트 만들기
2. **Authentication → 로그인 방법 → 이메일/비밀번호** 사용 설정
3. **Firestore Database** 만들기 (프로덕션 모드) → 규칙 탭에 `firestore.rules` 내용 붙여넣기
4. 프로젝트 설정 → 내 앱(웹) 추가 → 구성 값을 `js/config.example.js`를 복사한 `js/config.js`에 붙여넣기
5. Authentication → 사용자 추가에서 사장님 계정 만들기: 이메일 `minji@sonjoy.cafe`, 비밀번호 6자 이상
6. GitHub Pages(설정 → Pages → main 브랜치)로 배포하고, Authentication → 설정 → 승인된 도메인에 `thsalswl900119-maker.github.io` 추가
7. 앱에 로그인하면 첫 사용자가 자동으로 사장(owner)이 됩니다. 설정 → 직원 추가로 직원 계정을 만듭니다.

> 직원 로그인 아이디는 `이메일 앞부분`입니다. 예: `hyebin@sonjoy.cafe` → 아이디 `hyebin`
