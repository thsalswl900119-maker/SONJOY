# 카페스이 릴스 자동 편집기 (작은 버전)

찍은 영상 하나를 넣으면 **쉬는 구간 컷 · 목소리 크기 맞추기 · 자막 파일 · 자막 입힌 영상**이 나옵니다.
「AI 영상 편집기 도구 9개」 설계도 중 효과가 큰 앞부분(받아 적기 → 쉬는 구간 자르기 → 자막)만 먼저 만든 것입니다.

| 단계 | 도구 | 결과 파일 |
|---|---|---|
| ① 쉬는 구간 찾고 자르기 · 소리 크기 맞추기 | Silero VAD(faster-whisper 안에 들어 있음) + ffmpeg | `1_컷편집.mp4` |
| ② 받아 적기 · 단어마다 시간 | faster-whisper | `받아적기.txt` · `단어시간.json` |
| ③ 자막 줄 나누기(한 줄 16자) | 이 프로그램 | `2_자막.srt` |
| ④ 자막 입히기 | ffmpeg | `3_완성_자막입힘.mp4` |

## 설치 (컴퓨터에서 한 번만)

필요한 것: **Python 3.10 이상 · ffmpeg**. 클로드 코드에게 아래를 그대로 붙여 넣으면 알아서 확인 · 설치합니다.

```
SONJOY 저장소의 tools/reels 폴더에 있는 릴스 편집기를 내 컴퓨터에서 쓰려고 해.
1) ffmpeg와 Python(3.10 이상)이 있는지 확인하고 없으면 내 운영체제에 맞게 설치해줘.
2) tools/reels 폴더에 가상환경(.venv)을 만들고 requirements.txt를 설치해줘.
3) 아무 짧은 영상으로 `python reels.py 영상.mp4 --model small` 을 한 번 돌려서 결과 폴더가 생기는지 확인해줘.
설치할 때마다 무엇을 왜 하는지 한 줄로 설명해줘.
```

직접 할 때:

```bash
# 맥: brew install ffmpeg   /  윈도우: winget install ffmpeg
cd tools/reels
python3 -m venv .venv && source .venv/bin/activate    # 윈도우: .venv\Scripts\activate
pip install -r requirements.txt
```

처음 받아 적을 때 모델(small 약 500MB)을 한 번 내려받습니다.

## 쓰는 법

```bash
python reels.py 영상.mp4                       # 말하는 영상: 컷 + 자막 + 자막 입힘
python reels.py 영상.mp4 --script 대본.txt     # 대본이 있으면 받아 적기가 더 정확
python reels.py 영상.mp4 --no-cut              # 제품 · 과정 영상(자르면 안 됨): 자막만
python reels.py 영상.mp4 --no-subs             # 컷 편집만
python reels.py 영상.mp4 --model medium        # 더 정확(느림). 가장 정확: large-v3
```

결과는 `영상이름_결과/` 폴더에 생깁니다.

**자막 고치기**: `2_자막.srt`를 메모장으로 열어 틀린 글자만 고친 뒤

```bash
python reels.py 영상이름_결과/1_컷편집.mp4 --burn-only 영상이름_결과/2_자막.srt
```

또는 `2_자막.srt`를 캡컷 · 브루에 불러와 그 앱에서 꾸며도 됩니다.

## 조절할 수 있는 것

| 옵션 | 기본 | 뜻 |
|---|---|---|
| `--min-gap` | 0.35 | 이 초보다 긴 쉼만 자름. 말이 너무 빡빡하면 0.5 |
| `--pad` | 0.12 | 말 앞뒤로 남기는 여유. 끝 글자가 잘리면 0.2 |
| `--max-chars` | 16 | 자막 한 줄 글자 수 |
| `--font` | 맥 Apple SD Gothic Neo · 윈도우 맑은 고딕 | 자막 글꼴 |
| `--no-loud` | – | 목소리 크기 맞추기 안 함(배경음악 영상) |

## 카페스이 낱말 사전 (`glossary.txt`)

메뉴 이름처럼 받아 적기가 잘 틀리는 낱말을 적어 둡니다. 한 줄에 하나.
- 그냥 낱말(예: `천혜향`) → 받아 적을 때 힌트
- `틀린말=맞는말`(예: `천해향=천혜향`) → 자막에서 자동으로 고침. 영상마다 틀린 것을 보고 계속 더하면 점점 정확해집니다.

## 주의

- **자막은 꼭 한 번 눈으로 확인** — 메뉴 이름 · 숫자(가격 · 날짜)는 틀리면 바로 손님 안내 오류가 됩니다.
- 레시피 · 교육 영상은 공개 채널에 올리지 않기.
- 배경음악이 큰 영상은 쉬는 구간을 못 찾을 수 있음 → `--no-cut`.
